Я постарался сделать получение информации максимально удобным и красивым:

- Адаптивная вёрстка для просмотра на мобильных устройствах
- Переводы для языков на которых я говорю
- Цветовые решение благодаря <https://tweakcn.com/>
- Переключение светлая/тёмная тема
- Автоматический деплой на Firebase через GitHub экшены

# Стек

- React (19)
- Tailwind CSS + shadcn/ui
- bun (1.3.0)
- Vite (7)
- Firebase (хостинг, CD)

Хоть я и большой фанат архитектуры `FSD`, я специально решил обходиться здесь без неё, ибо не планирую чтобы размер проекта когда либо достиг точки в которой она была бы оправдана

# Запуск

Если вам интересно спуллить и запустить проект, не нужно делать никаких дополнительных настроек или конфигурации окружения, достаточно просто:

```bash
bun install
bun run dev
```
